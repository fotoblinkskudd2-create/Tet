# Råideer

Dette er testdata for OpenClaw Value Engine. Hver idé er en egen seksjon som
starter med `## Idea: <navn>` og har felter på formen `Felt: verdi`.
Parseren krever at hver idé har minst: Kategori, Problem, Hvem betaler,
Første salgbare leveranse, Teknisk vanskelighet, Markedsverdi, Byggbarhet,
Dokumentasjonsverdi og Risiko.
