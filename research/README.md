# Forskning: Biomimikk – insekter/dyr → dronedesign

En akademisk syntese på prinsippnivå om hvordan insekters og dyrs defensive/offensive
mekanismer og kollektive strategier kan inspirere autonomi- og svermdesign. Innretning:
sivile/forsvarlige/etisk forsvarbare bruksområder (søk-og-redning, inspeksjon, miljøovervåking).

## Struktur (4 deler)

1. **Insektenes defensive og offensive mekanismer** – bombardebille, felle-kjeve-maur,
   juvelveps, termitt-autothysis, heat-balling, sansevåpen, kamuflasje/mimikk.
2. **Insektvåpen → dronedesign** – pulset effekt, katapultstart, optisk flyt/event-kamera,
   sparsom deteksjon, lav signatur, heterogene mikrosvermer.
3. **Dyrs intelligente kampstrategier** – rovdyr, byttedyrforsvar, gruppedynamikk,
   miljøbruk, kommunikasjon.
4. **Teoretisk implementering** – ACO, PSO/boids, nevromorf sensorfusjon, auksjonsbasert
   oppgaveallokering, energibevisst planlegging.

## Fire røde tråder

**Asymmetri · Energiøkonomi · Sparsom sansing-handling · Desentralisert robusthet**

## Forbehold

Dokumentene skiller eksplisitt mellom **dokumentert vitenskap** og **teoretisk spekulasjon**,
angir usikkerhet, og holder ikke-overførbare mekanismer (kjemisk/eksplosiv våpenisering,
mållegging mot mennesker) på inspirasjonsnivå – med henvisning til humanitærrett/FN CCW-prosessen
om autonome våpen.
