# 🧠 AI for Normale Folk

En micro-app for folk som er lei av ekspert-tullball om AI.

## Hva er dette?

En interaktiv læringsapp med 10 korte moduler om AI - skrevet på norsk, uten jargong, med humor og praksis.

## Funksjoner

- **10 korte læringmoduler** - Alt fra "Hva er AI?" til "Framtiden uten sci-fi BS"
- **Progress tracking** - Automatisk lagring av fremgang i localStorage
- **Interaktiv navigasjon** - Gå fram/tilbake, hopp til moduler, eller følg rekkefølgen
- **Casual tone** - Ingen ekspert-språk, bare ærlige forklaringer
- **Dark mode design** - Behagelig for øynene

## De 10 Modulene

1. 🤖 **Hva er AI egentlig?** - Demystifisering uten hype
2. 💬 **Hvordan ChatGPT faktisk funker** - Enkel forklaring av språkmodeller
3. 🎯 **Prompt engineering** - Få bedre svar fra AI
4. 🚫 **Ting AI suger på** - Realisme om begrensninger
5. 🤪 **Hvorfor AI noen ganger er rart** - Om bias og treningsdata
6. 🛠️ **AI-verktøy du faktisk bør prøve** - Praktisk liste
7. 💼 **Tar AI jobben min?** - Ærlig perspektiv
8. 🎨 **AI og kreativitet** - Samarbeid, ikke konkurranse
9. 🔒 **Personvern og AI** - Hva du må passe på
10. 🔮 **Framtiden for AI** - Uten sci-fi BS

## Teknisk Info

- **Framework**: Next.js (React + TypeScript)
- **Filplassering**: `/frontend/src/pages/ai-for-normal-people.tsx`
- **Route**: `/ai-for-normal-people` når appen kjører
- **Styling**: Inline CSS-in-JS (dark theme)
- **State management**: React hooks (useState, useEffect)
- **Persistence**: localStorage for progress tracking

## Hvordan Bruke

1. Start Next.js dev server:
   ```bash
   cd frontend
   npm run dev
   ```

2. Gå til: `http://localhost:3000/ai-for-normal-people`

3. Les gjennom modulene i rekkefølge eller hopp rundt

4. Fremgang lagres automatisk

## Design Filosofi

- **Anti-expert**: Skrevet som en venn forklarer til en venn
- **Praktisk**: Fokus på hva du faktisk kan bruke
- **Ærlig**: Både fordeler og ulemper med AI
- **Norsk**: På norsk, fordi hvorfor ikke?
- **Gøy**: Emojis, humor, og lett tone
