# Ti magiske research-emner

Temaer for utforskning og fordypning.

1. **Bevissthetens natur**
   Interessant fordi vitenskapen fortsatt ikke fullt ut kan forklare hvordan
   subjektiv opplevelse oppstår.

2. **Synkronisitet**
   Jung beskrev meningsfulle tilfeldigheter. Verdt å undersøke som psykologi,
   mønstergjenkjenning og menneskelig mening.

3. **Drømmer og lucid dreaming**
   Gir innsikt i hukommelse, frykt, kreativitet og selvbevissthet.

4. **Gamle mysteriekulter**
   Eleusinske mysterier, orfisme og andre tradisjoner kan si mye om ritualer,
   transformasjon og kollektiv psykologi.

5. **Placeboeffekten**
   Fascinerende fordi tro, forventning og kroppslig respons kan skape målbare
   biologiske effekter.

6. **Hellige steder og kraftsteder**
   Undersøk hvorfor bestemte steder gjennom historien oppleves som hellige,
   sterke eller transformative.

7. **Alkymi som symbolsystem**
   Ikke bare som proto-kjemi, men som psykologisk og spirituelt språk for endring.

8. **Nær-døden-opplevelser**
   Krever nøktern forskning fordi de berører nevrologi, bevissthet, kultur og
   eksistensielle spørsmål.

9. **Sjamanistiske praksiser**
   Interessant som studie av transe, rytme, helbredelsesritualer og menneskets
   forhold til naturen.

10. **Tidens subjektive natur**
    Hvordan tid oppleves ulikt i krise, meditasjon, kreativ flyt, traume og dyp
    konsentrasjon.
