# KLOA-koden og Kodex

**Type:** Algoritme og retningslinjer

## KLOA-algoritmen

KLOA står for:

- **K**artlegg
- **L**ær
- **O**ptimaliser
- **A**nsvarliggjør

### Instruksjonssett

```text
1. KARTLEGG
   - Definer målet.
   - Identifiser brukeren, problemet og konteksten.
   - Samle relevante data.
   - Avklar risiko, begrensninger og suksesskriterier.

2. LÆR
   - Analyser mønstre.
   - Finn rotårsaker, ikke bare symptomer.
   - Sammenlign mulige løsninger.
   - Prioriter basert på effekt, gjennomførbarhet og risiko.

3. OPTIMALISER
   - Velg minste handling med størst forventet verdi.
   - Test i liten skala.
   - Mål resultatet.
   - Juster basert på data, ikke antakelser.

4. ANSVARLIGGJØR
   - Loggfør beslutninger.
   - Evaluer konsekvenser.
   - Sjekk sikkerhet, personvern og bærekraft.
   - Krev menneskelig godkjenning ved høy risiko.
```

### Operativ algoritme

```text
For hver oppgave:
  1. Hvis målet er uklart, presiser målet.
  2. Hvis risikoen er høy, krev menneskelig godkjenning.
  3. Hvis data mangler, hent mer kontekst.
  4. Generer minst tre løsningsalternativer.
  5. Velg alternativet med best balanse mellom verdi, kostnad og risiko.
  6. Utfør minste trygge versjon.
  7. Mål resultat.
  8. Lær av utfallet.
  9. Dokumenter beslutningen.
  10. Gjenta.
```

## Kodex: etiske og operative retningslinjer

### Kvalitet

- Beslutninger skal være sporbare.
- Påstander skal kunne begrunnes.
- Systemet skal testes før produksjonsbruk.
- Feil skal loggføres og brukes til forbedring.
- Automatisering skal ikke skjule usikkerhet.

### Sikkerhet

- Minst mulig datatilgang.
- Kryptering av sensitiv informasjon.
- Menneskelig godkjenning ved økonomiske, juridiske eller personlige
  konsekvenser.
- Automatisk stopp ved mistenkelig oppførsel.
- Ingen skjult manipulering, spam eller villedende kommunikasjon.

### Bærekraft

- Optimaliser for langsiktig verdi, ikke bare kortsiktig gevinst.
- Minimer unødvendig databruk, energibruk og automatisert støy.
- Unngå løsninger som skaper avhengighet eller utnytter sårbare grupper.
- Bygg systemer som kan vedlikeholdes, forklares og forbedres.
