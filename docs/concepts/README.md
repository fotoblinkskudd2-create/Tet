# Konsept- og idébank

En samling konsepter, ideer og prosjektskisser. Dokumentene er ment som
arbeidsgrunnlag: råmateriale for videre utvikling, ikke ferdige spesifikasjoner.

## Innhold

| # | Dokument | Tema |

| 1 | [HverdagsPilot](01-hverdagspilot.md) | Ideell oppfinnelse: AI-driftsassistent for hjemmet |
| 2 | [VibePassport](02-vibepassport.md) | Viralt konsept: global ungdomsbevegelse av «vibe-stempler» |
| 3 | [24/7 Value Engine](03-value-engine.md) | Arkitektur for autonome agenter med sikkerhetsgrenser |
| 4 | [KLOA-koden og Kodex](04-kloa-kode-og-kodex.md) | Algoritme og etiske/operative retningslinjer |

| 6 | [Ti kreative prosjekter](06-ti-kreative-prosjekter.md) | Kunst, video, tekst og installasjoner |
| 7 | [Ti magiske research-emner](07-ti-magiske-research-emner.md) | Temaer for utforskning og fordypning |

## Bruk

Hvert dokument står selvstendig. Begynn med oversikten over, og åpne det
dokumentet som er mest relevant for arbeidet du gjør nå.
