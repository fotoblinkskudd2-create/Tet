# VibeForge — The Ultimate Vibe Coding Studio

Describe your app idea + vibe, and VibeForge generates a complete production-ready Next.js project.

## Features

- **10 Live Vibes**: Cyberpunk, Zen, Brutalist, Retro CRT, Luxury, Hacker, Kawaii, Dark Void, Synthwave, Glassmorphism — click to instantly transform the entire UI
- **Forge Engine**: Describe your app in natural language, get a full project plan + generated code
- **Syntax Highlighting**: Shiki-powered code blocks with copy support
- **Download ZIP**: Export complete Next.js project ready for `vercel deploy`
- **Ambient Sound**: Lo-Fi, Synthwave, and Ambient tracks via Howler.js
- **API Key Settings**: Connect Grok or Claude for AI-powered generation
- **Premium UX**: Glassmorphism, micro-animations, canvas background effects, dark-first design

## Tech Stack

- Next.js 15 (App Router)
- TypeScript (strict mode)
- Tailwind CSS v4
- shadcn/ui components
- Framer Motion animations
- Shiki syntax highlighting
- Howler.js ambient audio
- JSZip for project export
- Sonner toast notifications
- Lucide icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

1. **Pick a vibe** from the sidebar (or use the mobile menu)
2. **Describe your app** in the main input area
3. **Click Forge** to generate a complete project
4. **Browse** the Plan, Code, Preview, and Docs tabs
5. **Download** as ZIP or copy all code
6. **Toggle** ambient sound for the perfect coding atmosphere

## Deploy

```bash
npx vercel
```
