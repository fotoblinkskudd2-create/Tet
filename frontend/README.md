# Hovda Husarbeid - iOS Web Prototype

A fun, gamified iOS-style web app that makes household chores enjoyable! 🎉

## Features

### 🏠 Main Chore Tracker (`/ios/chores`)
- Interactive chore list with fun emojis
- Point system for completed tasks
- Difficulty levels (easy, medium, hard)
- Real-time progress tracking
- Confetti animation on completion
- Level system that increases with points
- Beautiful gradient UI with glassmorphism effects

### 📊 Statistics Page (`/ios/stats`)
- Weekly completion chart
- Achievement system with unlockable badges
- Streak tracking
- Trophy collection
- Visual progress indicators

### 🏆 Rewards Page (`/ios/rewards`)
- Unlockable rewards using earned points
- Fun incentives like pizza night, gaming time, ice cream
- Point balance display
- Success notifications

## Design Features

- iOS-style interface with blur effects
- Smooth animations using Framer Motion
- Responsive gradient backgrounds
- Status bar simulation
- Bottom navigation bar
- Norwegian language UI

## Getting Started

### Installation

```bash
cd frontend
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:3000` to see the app!

### Build

```bash
npm run build
npm start
```

## Technologies

- **Next.js** - React framework
- **TypeScript** - Type safety
- **Framer Motion** - Smooth animations
- **React Hooks** - State management

## How It Works

1. Complete chores to earn points
2. Different difficulties give different points:
   - Easy tasks: 15-25 points
   - Medium tasks: 30-35 points
   - Hard tasks: 50+ points
3. Level up as you earn more points (100 points per level)
4. Unlock rewards with your earned points
5. Track your progress and achievements
