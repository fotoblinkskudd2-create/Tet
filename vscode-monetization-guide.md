## 1. Sell Code Snippets & Templates

**Skill Level:** Beginner

### Description
Package reusable code — starter projects, UI component kits, boilerplate repos, configuration files — and sell them on digital marketplaces. Buyers are developers or small teams who prefer to pay $5–$50 rather than build from scratch.

### VS Code Relevance
| Feature | How It Helps |
|---------|-------------|
| **User Snippets** (`File > Preferences > Configure User Snippets`) | Author `.code-snippets` files that customers drop into their workspace |
| **Workspace Settings / `.vscode/`** | Bundle recommended extensions, debug configs, and tasks so the template works out of the box |
| **Live Share** | Demo templates to potential buyers in real time |
| **Extensions: Prettier, ESLint** | Ensure consistent, high-quality code before publishing |

### Estimated Income Potential
$50 – $500 / month (passive after initial creation; scales with catalogue size).

### Time Investment
3 – 6 hours / week to create, document, and market new templates.

### Resources
- [Gumroad](https://gumroad.com) — sell digital products with zero upfront cost
- [CodeCanyon (Envato)](https://codecanyon.net) — marketplace for code scripts and plugins
- [GitHub Template Repositories](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository) — publish templates others can clone
- [VS Code Snippet Generator](https://snippet-generator.app/) — quickly generate snippet JSON

## 2. Freelance Web / App Development

**Skill Level:** Beginner – Intermediate

### Description
Offer development services to clients through freelancing platforms or direct outreach. Projects range from simple landing pages ($200–$500) to full-stack applications ($2 000–$20 000+).

### VS Code Relevance
| Feature | How It Helps |
|---------|-------------|
| **Integrated Terminal** | Run builds, tests, and deployments without leaving the editor |
| **Debugger (Node, Python, etc.)** | Step through client bugs efficiently — faster delivery = higher hourly rate |
| **Remote - SSH / Containers / WSL** | Work directly on client servers or containerised environments |
| **GitLens Extension** | Navigate client codebases, understand blame history, review PRs |
| **Extensions: REST Client, Thunder Client** | Test APIs inline while building backends |
| **Profiles** | Switch between project-specific extension sets instantly |

### Estimated Income Potential
$500 – $5 000 / month (depends on hours worked, niche, and experience).

### Time Investment
10 – 40 hours / week.

### Resources
- [Upwork](https://upwork.com) — largest freelance marketplace
- [Toptal](https://toptal.com) — vetted freelance network (higher rates)
- [Fiverr](https://fiverr.com) — good for smaller, well-defined tasks
- [freeCodeCamp](https://www.freecodecamp.org) — free curriculum to fill skill gaps
- [The Odin Project](https://www.theodinproject.com) — full-stack learning path

## 3. Create & Sell VS Code Extensions

**Skill Level:** Intermediate

### Description
Build extensions that solve real developer pain points — themes, formatters, linters, language support, productivity tools, AI integrations. Monetise via the VS Code Marketplace (sponsorships / freemium), Open VSX, or your own site.

### VS Code Relevance
| Feature | How It Helps |
|---------|-------------|
| **Extension API** | Full access to editor events, commands, webviews, language servers |
| **Yeoman Generator (`yo code`)** | Scaffold a new extension in seconds |
| **Extension Development Host** | Press `F5` to launch a sandboxed VS Code instance for testing |
| **`vsce` CLI** | Package and publish directly to the Marketplace |
| **Webview API** | Build rich in-editor UIs with HTML/CSS/JS |

### Estimated Income Potential
$100 – $3 000 / month. Top extensions with freemium tiers or sponsorship buttons can earn significantly more.

### Time Investment
5 – 15 hours / week (heavier during initial development, lighter during maintenance).

### Monetisation Models
1. **Freemium** — free core + paid pro features (e.g., via Gumroad licence keys)
2. **Sponsorship** — GitHub Sponsors / Buy Me a Coffee links in the extension
3. **Marketplace Tips** — some marketplaces allow tipping
4. **Enterprise Licencing** — sell team/org licences for proprietary extensions

### Resources
- [VS Code Extension API Docs](https://code.visualstudio.com/api) — official documentation
- [Extension Samples (GitHub)](https://github.com/microsoft/vscode-extension-samples) — working examples
- [vsce Publishing Guide](https://code.visualstudio.com/api/working-with-extensions/publishing-extension) — step-by-step publishing
- [GitHub Sponsors](https://github.com/sponsors) — accept recurring funding from users

## 4. Open-Source Bounties & Bug Bounties

**Skill Level:** Intermediate

### Description
Earn money by fixing tagged issues in open-source repositories (bounty platforms) or by finding and reporting security vulnerabilities in software (bug bounty programmes).

### VS Code Relevance
| Feature | How It Helps |
|---------|-------------|
| **GitHub Pull Requests Extension** | Review, comment, and submit PRs without leaving VS Code |
| **Source Control Panel** | Stage, commit, and push changes with a visual diff |
| **Debugger** | Reproduce and fix bugs faster with breakpoints and watch variables |
| **Remote Repositories Extension** | Browse and edit any GitHub repo instantly, no clone needed |
| **CodeQL Extension** | Run static analysis to discover security vulnerabilities |

### Estimated Income Potential
$200 – $2 000 / month (highly variable; single high-severity bug bounties can pay $1 000–$50 000).

### Time Investment
5 – 15 hours / week.

### Resources
- [Algora](https://algora.io) — open-source bounty marketplace
- [IssueHunt](https://issuehunt.io) — fund and collect bounties on GitHub issues
- [HackerOne](https://hackerone.com) — security bug bounty platform
- [Bugcrowd](https://bugcrowd.com) — crowd-sourced security testing
- [OSS Bounties on GitHub](https://github.com/niceByte/bounties) — curated lists of bounty-tagged issues

## 5. Build & Sell SaaS / Digital Products

**Skill Level:** Advanced

### Description
Use VS Code as your primary IDE to build a software-as-a-service product, desktop app (Electron/Tauri), mobile app, or API service. Sell subscriptions, one-time licences, or usage-based access.

### VS Code Relevance
| Feature | How It Helps |
|---------|-------------|
| **Multi-Root Workspaces** | Manage monorepo (frontend + backend + infra) in one window |
| **Docker Extension** | Build, run, and debug containers for your SaaS stack |
| **Database Extensions (SQLTools, MongoDB)** | Query databases inline while developing |
| **Copilot / AI Extensions** | Accelerate boilerplate code and reduce time to MVP |
| **Tasks & Launch Configurations** | One-click commands to build, test, deploy |
| **Integrated Terminal + Multiple Shells** | Run parallel processes (API server, frontend dev server, workers) |

### Estimated Income Potential
$1 000 – $20 000+ / month (wide range; depends on product-market fit).

### Time Investment
15 – 40 hours / week (higher during build phase, lower during maintenance).

### Resources
- [Indie Hackers](https://indiehackers.com) — community and case studies of solo SaaS builders
- [Stripe](https://stripe.com/docs) — payment integration
- [Vercel](https://vercel.com) / [Railway](https://railway.app) — deploy full-stack apps quickly
- [Supabase](https://supabase.com) — open-source Firebase alternative (auth, DB, storage)
- [Plausible Analytics](https://plausible.io) — privacy-friendly analytics for your product

## 6. AI-Augmented Development Services

**Skill Level:** Intermediate – Advanced

### Description
Combine your VS Code proficiency with AI tools (Copilot, ChatGPT API, local LLMs) to offer accelerated development, code review, migration, and automation services. Clients pay premium rates because AI-augmented developers deliver faster.

### VS Code Relevance
| Feature | How It Helps |
|---------|-------------|
| **GitHub Copilot** | Autocomplete, chat, inline suggestions — dramatically speeds up coding |
| **Continue.dev Extension** | Connect local or remote LLMs (Ollama, OpenAI, Anthropic) for in-editor AI chat |
| **Copilot Chat** | Ask questions about the codebase, generate tests, explain code |
| **Jupyter Notebooks** | Prototype ML pipelines and data analysis directly in VS Code |
| **Python / Pylance Extensions** | First-class support for AI/ML development in Python |
| **REST Client** | Test AI API endpoints (OpenAI, Anthropic, Hugging Face) inline |

### Estimated Income Potential
$1 000 – $10 000 / month. AI-augmented developers can command 20–50 % higher rates than traditional freelancers for equivalent work.

### Time Investment
10 – 30 hours / week.

### How to Learn AI (Actionable Path)
This is the "learn AI" section — practical steps you can follow right now:

#### Step 1: Foundations (Week 1–4)
- **Python Basics** — if you don't already know Python, learn it inside VS Code with the Python extension
- **Prompt Engineering** — learn to write effective prompts for LLMs
- Resources:
  - [Andrej Karpathy's "Intro to LLMs" (YouTube)](https://www.youtube.com/watch?v=zjkBMFhNj_g)
  - [DeepLearning.AI Short Courses](https://www.deeplearning.ai/short-courses/) — free, hands-on courses
  - [fast.ai Practical Deep Learning](https://course.fast.ai) — free, project-based

#### Step 2: Build with AI APIs (Week 5–8)
- Use the **OpenAI**, **Anthropic**, or **Google Gemini** APIs to build small projects
- Install the **REST Client** extension in VS Code to test API calls inline
- Build: a chatbot, a summariser, a code reviewer, a document Q&A tool
- Resources:
  - [OpenAI Cookbook](https://cookbook.openai.com)
  - [Anthropic API Docs](https://docs.anthropic.com)
  - [LangChain](https://python.langchain.com) — framework for LLM apps
  - [LlamaIndex](https://www.llamaindex.ai) — framework for RAG (retrieval-augmented generation)

#### Step 3: Local LLMs & Fine-Tuning (Week 9–12)
- Run models locally with **Ollama** and connect to VS Code via Continue.dev
- Experiment with fine-tuning small models on custom datasets
- Resources:
  - [Ollama](https://ollama.com) — run LLMs locally
  - [Hugging Face](https://huggingface.co) — models, datasets, and training tools
  - [Together AI](https://together.ai) — affordable fine-tuning API

#### Step 4: Monetise Your AI Skills
- Offer AI integration consulting to businesses
- Build AI-powered tools/extensions and sell them
- Create content teaching others what you've learned

### Resources
- [GitHub Copilot](https://github.com/features/copilot) — AI pair programming
- [Continue.dev](https://continue.dev) — open-source AI code assistant for VS Code
- [Hugging Face](https://huggingface.co) — models, datasets, spaces
- [Kaggle](https://kaggle.com) — competitions, datasets, notebooks
- [Papers With Code](https://paperswithcode.com) — latest ML research with implementations

$100 – $5 000 / month (grows with audience size; top creators earn $10 000+/month).

5 – 20 hours / week.

## Getting Started Checklist

- [ ] **Pick ONE method** from the table above that matches your current skill level
- [ ] **Set up your VS Code environment** — install the relevant extensions listed for that method
- [ ] **Allocate a fixed number of hours per week** — consistency beats intensity
- [ ] **Ship something small in the first two weeks** — a snippet pack, a bounty fix, a tutorial, a landing page
- [ ] **Reinvest early earnings** into learning (courses, better tools, domains, hosting)
- [ ] **Track your income and hours** — know your effective hourly rate and optimise from there
- [ ] **Start learning AI** (Section 6) — AI skills are a multiplier on every other method in this guide
