## 31 — ShelterNow 🏠

> Kobler hjemløse med akutt-overnatting, matutdeling og sosiale tjenester i sanntid.

### 1. Toppopplysninger
- **App-navn:** ShelterNow | shelternow.app
- **Tagline:** Et trygt sted — alltid tilgjengelig.
- **Elevator pitch:** ShelterNow viser ledige plasser på herberger, matutdelinger og sosiale tjenester i sanntid — for de 150 M hjemløse globalt. Herberger oppdaterer kapasitet, brukere finner hjelp på kartet.
- **Problemkort:** 150 M hjemløse. I USA: 600K per natt. Herberger er ofte fulle, informasjon er fragmentert.

### 2. Produktoversikt
**Kjernefunksjoner:** Sanntids-kart over herberger/mattilbud med ledig kapasitet, GPS-navigasjon, filterering (kvinner, familier, kjæledyr), push-varsler ved ledige plasser, case worker-kobling, helseressurser.
**Personas:** Tom (45, nybli hjemløs), Sarah (28, sosialarbeider), Maria (50, herberge-leder).
**Konkurrenter:** Homeless Shelter Directory (statisk), Link-SF (kun SF), Streetlives.

### 3. Tekniske spesifikasjoner
**Stack:** React Native (offline-first) + Next.js (admin) + Node.js + PostgreSQL/PostGIS + Mapbox.
**APIer:** `GET /shelters?lat=&lng=&r=&type=`, `PUT /shelters/:id/capacity`, `GET /services?category=`.
**Datamodeller:** `shelters` (name, lat, lng, type, capacity, available, rules), `services` (food, health, legal), `checkins`.

### 4. Implementasjon
**MVP:** 7 uker. Kart + herberge-kapasitet + navigasjon.
**Kostnad:** Lean $18K, Standard $50K, Full $110K.

### 5. Kodeeksempel (Backend)

```typescript
router.get("/v1/shelters", async (req, res) => {
  const { lat, lng, r = 5, type } = req.query;
  let query = `SELECT *, ST_Distance(location, ST_MakePoint($1,$2)::geography)/1000 as distance_km
    FROM shelters WHERE ST_DWithin(location, ST_MakePoint($1,$2)::geography, $3*1000)
    AND available > 0`;
  const params = [lng, lat, r];
  if (type) { query += ` AND type = $4`; params.push(type); }
  query += ` ORDER BY distance_km`;
  const shelters = await db.query(query, params);
  res.json(shelters.rows);
});
```

### 6. Go-to-market
**Modell:** Gratis for brukere. B2G kommune $500–5K/mnd. NGO-partnerskap. Grant-finansiert.

router.get("/v1/toilets", async (req, res) => {
  const { lat, lng, r = 1, accessible } = req.query;
  let query = `SELECT *, ST_Distance(location, ST_MakePoint($1,$2)::geography) as distance_m
    FROM toilets WHERE ST_DWithin(location, ST_MakePoint($1,$2)::geography, $3*1000)`;
  const params: any[] = [lng, lat, r];
  if (accessible === "true") { query += ` AND wheelchair_accessible = true`; }
  query += ` ORDER BY distance_m LIMIT 50`;
