## Markedspotensial (forklaring)

- **Høy** = TAM > $10 mrd, voksende marked, klar betalingsvilje
- **Moderat** = TAM $1–10 mrd, eller avhengig av B2B/B2G-salg
- **Lav** = TAM < $1 mrd, nisjemarked

## Prioriteringsscore (1–10)

Basert på: (a) størrelse på problemet, (b) teknisk løsbarhet via app, (c) markedspotensial, (d) differensieringsmulighet, (e) regulatorisk risiko.
