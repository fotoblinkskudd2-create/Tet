## 06 — ElderConnect 👴

> Bekjemper ensomhet blant eldre med AI-kompanjonskap og sosialt nettverk.

### 1. Toppopplysninger
- **App-navn:** ElderConnect | elderconnect.app
- **Tagline:** Aldri alene — vennskap uten alder.
- **Elevator pitch:** ElderConnect kobler eldre med AI-kompanjonger, frivillige besøksvenner og jevnaldrende via video, tale og meldinger — designet med stor tekst, enkel UX og automatisk velværesjekk.
- **Problemkort:** 1,4 mrd eldre globalt opplever ensomhet. Ensomhet øker dødsrisiko med 26 %. Eldreomsorgsmarkedet: $1,9 trillion.

### 2. Produktoversikt
**Kjernefunksjoner:** AI-samtalepartner (tale/tekst), videosamtaler med frivillige, daglig velværesjekk (humør + helse), aktivitetsforslag, familievarslinger, lokale arrangementer.
**Personas:** Gerd (82, bor alene), Erik (55, sønn/omsorgsperson), Lisa (25, frivillig).
**Use cases:** Gerd prater med AI-kompanjon kl. 10 → sier hun er ensom → app foreslår videosamtale med Lisa → Gerd føler seg bedre → Erik får varsel om at mamma er ok.
**Konkurrenter:** GrandPad (hardware-fokus), Papa (menneskelig assistanse, dyrt), Replika (ikke eldre-tilpasset).

### 3. Tekniske spesifikasjoner
**Stack:** iOS SwiftUI + Next.js + Node.js/Express + PostgreSQL + OpenAI GPT-4o (tale) + Twilio (video) + FCM.
**Nøkkel-APIer:** `POST /checkin` (daglig sjekk), `GET /companions` (match), `POST /call/start` (video), `GET /alerts` (familie).
**Datamodeller:** `users`, `checkins` (mood, health_score, notes), `matches` (elder_id, volunteer_id), `calls`, `family_links`.
**Sikkerhet:** HIPAA-kompatibel helsedata, biometrisk innlogging, ingen persondata delt med frivillige uten samtykke.

### 4. Implementasjon
**MVP:** 8 uker (2 fullstack + 1 designer). Daglig velværesjekk + AI-samtalepartner + familievarsling.
**Kostnad:** Lean $20K, Standard $65K, Full $140K.
**Stack-detaljer:** Twilio Video $0.004/min, OpenAI ~$0.03/samtale.

### 5. Kodeeksempel (Backend)

```typescript
// ElderConnect — daglig velværesjekk-endepunkt
import express from "express";
const router = express.Router();

router.post("/v1/checkin", async (req, res) => {
  const { userId, mood, healthScore, notes } = req.body;
  const checkin = { id: `chk_${Date.now()}`, userId, mood, healthScore, notes, createdAt: new Date().toISOString() };
  // Lagre i DB + sjekk for bekymring
  if (mood <= 2 || healthScore <= 3) {
    // Send varsel til familie
    await notifyFamily(userId, { type: "concern", mood, healthScore });
  }
  res.status(201).json(checkin);
});
```

### 6. Design
**Farger:** Varm blå #4A90D9, myk gul #FFF3CD, stor tekst (20px+).
**Nøkkelprinsipp:** Maks 3 knapper per skjerm, høy kontrast, VoiceOver-first.

### 7. Go-to-market
**Modell:** Freemium + Family $9,99/mnd + B2B sykehjem $12/beboer/mnd.
**Kanal:** Partnerskap med Røde Kors, senior-foreninger, kommuner.

### 8. Juridisk
GDPR + HIPAA, anonym frivillig-matching, bakgrunnssjekk for frivillige.

### 9. KPIer
6 mnd: 5K MAU, 1K daglige sjekk-inn. 12 mnd: 30K MAU, 500 aktive frivillige.

## 07 — SleepReset 😴

- **Problemkort:** 45 % av verdens befolkning sover for dårlig. Insomni koster $411 mrd/år i produktivitetstap. Søvn-app-marked: $4,5 mrd.
